# Controllers

- [ProvenanceController.js](ProvenanceController.js) — records user interactions and manages modes/sampling.
- [provenanceSerialization.js](provenanceSerialization.js) — validates v2 data and converts PW1 data.
- [widgetRegistry.js](widgetRegistry.js) — validates and updates widget registrations.
- [superProvenanceReplay.js](superProvenanceReplay.js) — restores registered widgets from history.
- [index.js](index.js) — exposes the controller APIs used by ProvenanceWidgets.
- [ProvenanceController.d.ts](ProvenanceController.d.ts) — TypeScript type declarations for `ProvenanceController`.
