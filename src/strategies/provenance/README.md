# Provenance

- [Provenance.ts](Provenance.ts) — common time, index, aggregate, and detailed storage.
- [GenericProvenance.ts](GenericProvenance.ts) — histories for arbitrary keyed values.
- [TextProvenance.ts](TextProvenance.ts) — the string specialization of the generic strategy.
- [NumericProvenance.ts](NumericProvenance.ts) — numeric histories with minimum and maximum bounds.
- [RangedProvenance.ts](RangedProvenance.ts) — overlapping range history and aggregate intervals.
- [SelectionProvenance.ts](SelectionProvenance.ts) — select/unselect history for option sets.
- [SuperProvenance.ts](SuperProvenance.ts) — interaction history across registered widgets.
- [index.ts](index.ts) — re-exports every strategy from this folder.
